# RobotDSL

Community site of the RobotDSL project and the static preview of MobileCopilot Studio.

- `index.html`, `assets/` — the project page (MobileDSL 1.0, MobileCopilot, results, real-robot runs, community).
- `studio/` — MobileCopilot Studio front end with the component library and thumbnails. This static copy has no compiler behind it: the library, the editors and the key guide work; Build, Copilot and exports need the hosted service.

Questions, designs and announcements: use Discussions. Problems with a generated design or the site: open an Issue.
